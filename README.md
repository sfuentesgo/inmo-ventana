# Inmo-Ventana | Motor de Navegación Arquitectónica

Prototipo funcional para la optimización de rutas de navegación y recomendación de vivienda en venta en Bogotá y La Sabana, aplicando los patrones **Strategy**, **Iterator** y **Cache-Aside** sobre FastAPI.

## Ejecución local
``bash
pip install -r requirements.txt
uvicorn src.main:app --reload
``
